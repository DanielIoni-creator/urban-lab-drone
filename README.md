# 🛸 Urban Lab Drone – Droni open source per un mondo migliore

Benvenuto nel repository dei droni Urban Lab. Qui trovi tutto per costruire, programmare e utilizzare droni open source.

## 📦 Specifiche tecniche

| Componente | Dettaglio |
|------------|-----------|
| **Motori** | 4x Brushless 2212 920kV |
| **ESC** | 4x 30A |
| **Batteria** | LiPo 4S 5200mAh |
| **Autonomia** | 20-30 minuti |
| **Raggio d'azione** | 5 km (con telemetria) |
| **Carico utile** | 1 kg |
| **Velocità max** | 60 km/h |
| **Sensori** | GPS, accelerometro, giroscopio, barometro |

## 💰 Pagamenti e ricompense

- **Noleggio**: pagamento in XMR con escrow multisig
- **Ricompense**: 0.5 MYZ per ogni km volato
- **Bonus**: 20 MYZ ogni 100 km

## 📂 Contenuto

- `cad/` – File CAD (STEP, STL, F3D)
- `firmware/` – Firmware per ESP32
- `bom/` – Bill of Materials
- `assembly/` – Guide di assemblaggio
- `docs/` – Documentazione tecnica
